microsoft.scom.notification_subscription module – Manage SCOM notification subscriptions.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.notification_subscription.

New in microsoft.scom 2.0.0

Synopsis

  • Creates or removes a SCOM alert notification subscription.

  • A subscription routes alert notifications to one or more subscribers through one or more notification channels.

  • The referenced channels and subscribers must already exist. Create them first with the microsoft.scom.notification_channel and microsoft.scom.notification_subscriber modules.

  • When a subscription already exists the following fields can be updated in place subscribers.

  • Existing subscriptions can be enabled or disabled with enabled parameter.

  • channels and criteria cannot be changed on an existing subscription.

  • A warning is emitted if the desired channels or criteria differ from the current ones; remove the subscription with state=absent and recreate it to change channels or criteria.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

channels

list / elements=string

The display names of the notification channels used to deliver notifications.

Required when creating a new subscription (state=present and the subscription does not yet exist).

Cannot be changed once a subscription exists. A warning is emitted if the desired list differs from the current channels; remove the subscription with state=absent and recreate it to change channels.

Each channel must already exist.

criteria

dictionary

Structured alert filter applied when the subscription is created.

Criteria cannot be changed on an existing subscription. A warning is emitted if criteria is specified for a subscription that already exists; remove it with state=absent and recreate it to apply new criteria.

filters

list / elements=dictionary / required

One or more alert property filters.

operator

string / required

Comparison operator applied between the property and the value.

Choices:

  • "equal"

  • "not_equal"

  • "greater"

  • "greater_equal"

  • "less"

  • "less_equal"

property

string / required

The alert property to filter on.

severity — alert severity level.

priority — alert priority level.

Choices:

  • "severity"

  • "priority"

value

string / required

The value to compare against.

Severity values — critical=2, warning=1, information=0.

Priority values — high=2, medium=1, low=0.

Choices:

  • "critical"

  • "warning"

  • "information"

  • "high"

  • "medium"

  • "low"

group_operator

string

How multiple filters are combined. Required when criteria.filters contains more than one entry.

and — all filters must match.

or — any filter must match.

Ignored when criteria.filters contains only one entry.

Choices:

  • "and"

  • "or"

description

string

A free-text description for the subscription.

display_name

string

The display name of the subscription.

Defaults to the value of name when not provided.

enabled

boolean

Whether the subscription is enabled.

When state=present and the subscription already exists, the module enables or disables it to match this value.

Choices:

  • false

  • true

name

string / required

The internal name of the subscription, used as the identity for idempotency.

Must be a valid SCOM management pack identifier - it must start with a letter or underscore and contain only letters, digits, underscores, and dots (no spaces).

Use display_name for a human-friendly label.

state

string

present ensures the subscription exists, creating it if necessary.

absent removes the subscription if it exists.

Choices:

  • "present" ← (default)

  • "absent"

subscribers

list / elements=string

The names of the notification subscribers that receive notifications.

Required when creating a new subscription (state=present and the subscription does not yet exist).

When the subscription already exists and this list is non-empty, the module compares it with the current subscribers and updates them in place if they differ.

Leave unset when only toggling enabled on an existing subscription.

Each subscriber must already exist.

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Create a notification subscription
  microsoft.scom.notification_subscription:
    name: "CriticalAlertsToOps"
    display_name: "Critical Alerts to Operations"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: true

- name: Create a subscription filtered to Warning and Critical alerts only
  microsoft.scom.notification_subscription:
    name: "WarnCritAlertsToOps"
    display_name: "Warning and Critical Alerts to Operations"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: true
    criteria:
      filters:
        - property: severity
          operator: greater
          value: information

- name: Create a subscription filtered to Critical alerts only
  microsoft.scom.notification_subscription:
    name: "CriticalAlertsToOps"
    display_name: "Critical Alerts to Operations"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: true
    criteria:
      filters:
        - property: severity
          operator: equal
          value: critical

- name: Create a subscription filtered to Critical AND High-priority alerts
  microsoft.scom.notification_subscription:
    name: "CritHighPriorityAlerts"
    display_name: "Critical High-Priority Alerts"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: true
    criteria:
      group_operator: and
      filters:
        - property: severity
          operator: equal
          value: critical
        - property: priority
          operator: equal
          value: high

- name: Create a subscription for Warning OR Critical alerts
  microsoft.scom.notification_subscription:
    name: "WarnOrCritAlerts"
    display_name: "Warning or Critical Alerts"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: true
    criteria:
      group_operator: or
      filters:
        - property: severity
          operator: equal
          value: warning
        - property: severity
          operator: equal
          value: critical

- name: Create a disabled subscription
  microsoft.scom.notification_subscription:
    name: "WarningAlertsToOps"
    display_name: "Warning Alerts to Operations"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
      - "On-call Engineers"
    enabled: false

- name: Remove a notification subscription
  microsoft.scom.notification_subscription:
    name: "CriticalAlertsToOps"
    state: absent

- name: Disable an existing subscription
  microsoft.scom.notification_subscription:
    name: "CriticalAlertsToOps"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: false

- name: Re-enable an existing subscription
  microsoft.scom.notification_subscription:
    name: "CriticalAlertsToOps"
    channels:
      - "Ops Email Channel"
    subscribers:
      - "Operations Team"
    enabled: true
