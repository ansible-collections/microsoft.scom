microsoft.scom.monitor_override module – Manage SCOM monitor overrides.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.monitor_override.

Synopsis

  • Changes the value of an override that is already applied to a SCOM monitor.

  • This module can enable or disable a SCOM monitor for a specific class or group.

  • All overrides except for Enabled must already exist.

  • Use microsoft.scom.monitor_override_info to discover which overrides are in effect and their current values.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

management_pack

string

The internal name or display name of the unsealed management pack that will store a new Enabled override.

Only applies when creating a new override.

Not idempotent when Enabled already exists.

Not required for other properties.

monitor_id

string / required

The unique GUID of the monitor to act on.

Use microsoft.scom.monitor_override_info to find the monitor GUID.

override_property

string / required

The name of the monitor property whose override value should be changed.

Must be one of the system properties listed below, or a custom configuration parameter exposed by the monitor.

System (Enabled): Enabled

System (Alert): GenerateAlert, AutoResolve, AlertPriority, AlertSeverity, AlertOnState

Custom: any parameter name of the target monitor, e.g. Threshold, Timeout, IntervalSeconds.

override_value

string / required

The new value to set for the override.

For boolean properties (Enabled, AutoResolve, GenerateAlert) use true or false.

For AlertPriority: low, normal, high.

For AlertSeverity: information, warning, error, match_monitor_health.

For AlertOnState: error, warning.

For custom configuration parameters provide the raw value as a string (e.g. 300 for a timeout).

target

string / required

Whether the override is scoped to a class or a group.

Choices:

  • "class"

  • "group"

target_name

string / required

The display name of the class or group the override is scoped to.

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Disable monitor for the Gateway class
  microsoft.scom.monitor_override:
    monitor_id: "1acfe2b7-72ac-8975-8452-b343a8b581ed"
    override_property: Enabled
    override_value: "false"
    target: class
    target_name: "Gateway"
    management_pack: "AnsibleAlert"

- name: Re-enable monitor for the AD Assignment Resource Pool group
  microsoft.scom.monitor_override:
    monitor_id: "1acfe2b7-72ac-8975-8452-b343a8b581ed"
    override_property: Enabled
    override_value: "true"
    target: group
    target_name: "AD Assignment Resource Pool"
    management_pack: "AnsibleAlert"

- name: Change alert priority to High for a class-wide override
  microsoft.scom.monitor_override:
    monitor_id: "e389b054-48c8-f526-9572-1dba95ca753e"
    override_property: AlertPriority
    override_value: high
    target: class
    target_name: "CPU Processor (Bytemobile)"

- name: Change alert priority to High for a group-scoped override
  microsoft.scom.monitor_override:
    monitor_id: "1acfe2b7-72ac-8975-8452-b343a8b581ed"
    override_property: AlertPriority
    override_value: high
    target: group
    target_name: "AD Assignment Resource Pool"

- name: Update Threshold custom parameter for a class-wide override
  microsoft.scom.monitor_override:
    monitor_id: "e389b054-48c8-f526-9572-1dba95ca753e"
    override_property: Threshold
    override_value: "95"
    target: class
    target_name: "CPU Processor (Bytemobile)"

- name: Update Threshold custom parameter for a group-scoped override
  microsoft.scom.monitor_override:
    monitor_id: "1acfe2b7-72ac-8975-8452-b343a8b581ed"
    override_property: Threshold
    override_value: "95"
    target: group
    target_name: "AD Assignment Resource Pool"
