microsoft.scom.management_pack module – Import or remove SCOM management packs.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.management_pack.

Synopsis

  • Imports a SCOM management pack from a file, or removes an installed management pack.

  • Enables treating SCOM monitoring configuration as code.

  • Supports sealed (.mp, .mpb) and unsealed (.xml) management pack files.

  • Idempotent - when importing, no change is made if a management pack of the same identity and an equal or newer version is already installed.

  • Supports check mode.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

name

string

The identity name of the management pack (for example Microsoft.SQLServer.Windows.Monitoring).

Required when state=absent.

Use microsoft.scom.management_pack_info to discover management pack names.

path

string

Path on the SCOM management server to the management pack file to import.

Supports .xml (unsealed), .mp (sealed), and .mpb (sealed bundle) files.

Required when state=present.

state

string

present imports the management pack from path.

absent removes the installed management pack identified by name.

Choices:

  • "present" ← (default)

  • "absent"

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Import an unsealed management pack
  microsoft.scom.management_pack:
    path: 'C:\\MPs\\Contoso.Custom.Monitoring.xml'
    state: present

- name: Import a sealed management pack bundle
  microsoft.scom.management_pack:
    path: 'C:\\MPs\\Microsoft.SQLServer.Windows.mpb'
    state: present

- name: Remove a management pack by identity name
  microsoft.scom.management_pack:
    name: "Contoso.Custom.Monitoring"
    state: absent
