microsoft.scom.group module – Manage SCOM groups with explicit membership.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.group.

Synopsis

  • Creates or removes a SCOM instance group.

  • Membership is explicit (static) - each member is specified by its name or GUID.

  • Members can be any SCOM monitoring object type (Windows computers, IIS sites, application pools, health services, etc.).

  • An empty group is created when members is omitted or empty.

  • Idempotent by name and members - if the group already exists with the same membership the task reports changed=false. If the membership differs, the module updates the group discovery.

  • Supports check mode.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

display_name

string

The display name shown for the group in the Operations Console.

Defaults to name when not provided.

members

list / elements=string

The monitoring objects to include in the group as explicit (static) members.

Each entry is either a monitoring object GUID or a display name.

Members can be any SCOM monitoring object type - Windows computers, IIS sites, application pools, health services, etc.

Display names are resolved against all SCOM monitoring objects at run time.

The task fails when a display name matches zero objects with msg “Member does not exist in SCOM.”

The task uses the first object when a display name matches more than one object with msg “Supply the GUID directly if you need a specific class instance.”

When omitted or empty, an empty group is created - no members are added.

Members are idempotent - if the group already exists with the same membership, the task reports changed=false. If the membership differs, the module updates the group discovery.

Default: []

name

string / required

The internal name of the group, used as the identity of the backing management pack.

Must be a valid SCOM management pack identifier - it must start with a letter or underscore and contain only letters, digits, underscores, and dots (no spaces).

state

string

present ensures the group exists, creating it if necessary.

absent removes the group if it exists.

Choices:

  • "present" ← (default)

  • "absent"

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Create an empty group
  microsoft.scom.group:
    name: "Contoso.WebServers"
    display_name: "Contoso Web Servers"

- name: Create a group using display names (resolved automatically)
  microsoft.scom.group:
    name: "Contoso.Group"
    display_name: "Contoso Group"
    members:
        - "Action"
        - "WIN-Q37ISGBPHBE.eco.ansible.com"
        - ".NET v2.0 Classic"

- name: Create a group using GUIDs (use when display name is ambiguous)
  microsoft.scom.group:
    name: "Contoso.Group"
    display_name: "Contoso Group"
    members:
      - "50bda82b-51fa-6768-9045-15ca5fddc15d"
      - "08fa2fb9-8983-3849-764a-084aa391eaaf"
      - "dbfc4ab7-9673-ec12-670c-3418c382de50"

- name: Get member IDs from an existing group and reuse them
  microsoft.scom.group_info:
    display_name: "IIS Web Server"
  register: iis_group

- name: Create a group whose members come from a previous lookup
  microsoft.scom.group:
    name: "Contoso.IISServers"
    display_name: "Contoso IIS Servers"
    members: "{{ iis_group.groups | map(attribute='id') | list }}"

- name: Remove a group
  microsoft.scom.group:
    name: "Contoso.WebServers"
    state: absent

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

group

dictionary

The SCOM group after applying changes. Not returned when state=absent.

Returned: when state=present

configured_members

list / elements=dictionary

The monitoring object GUIDs stored in the management pack XML. Available immediately after import or in-place update - does not require GroupPopulator to have run. Use this field to verify the intended membership without waiting for the discovery cycle.

Returned: success

id

string

The monitoring object GUID as stored in the management pack.

Returned: success

display_name

string

The display name of the group.

Returned: success

full_name

string

The full internal name of the group class.

Returned: success

id

string

The internal GUID of the group.

Returned: success

management_pack

string

The management pack that defines the group.

Returned: success

members

list / elements=dictionary

The monitoring objects currently related to the group at runtime, as returned by SCOM’s GroupPopulator discovery. May be empty immediately after creation or update; use configured_members for immediate consistency checks.

Returned: success

display_name

string

The display name of the member monitoring object.

Returned: success

id

string

The internal GUID of the member monitoring object.

Returned: success

name

string

The full internal class name of the member monitoring object.

Returned: success

name

string

The full internal name of the group class.

Returned: success
