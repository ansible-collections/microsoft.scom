microsoft.scom.monitor_override_info module – Retrieve SCOM monitors and their overrides by Monitor ID, Display Name, or Target Class.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.monitor_override_info.

Synopsis

  • Returns one or more SCOM monitors together with all of their overrides.

  • The return values of this module can be used for the set module to modify the overrides.

  • This is a read-only module and never changes the SCOM environment.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

monitor_display_name

string

The display name of the monitor(s) to retrieve.

May match more than one monitor when monitors from different management packs share the same display name.

Mutually exclusive with monitor_id and monitor_target_class.

monitor_id

string

The unique GUID of the monitor to retrieve.

Returns at most one monitor.

Mutually exclusive with monitor_display_name and monitor_target_class.

monitor_target_class

string

The display name of the SCOM class whose monitors should be retrieved.

All monitors whose target class matches are returned, regardless of their display name.

Mutually exclusive with monitor_id and monitor_display_name.

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Get a single monitor by its GUID
  microsoft.scom.monitor_override_info:
    monitor_id: "5dbf2777-5537-e364-b1f9-3a2ca2da34ac"
  register: result

- name: Get all monitors whose display name matches
  microsoft.scom.monitor_override_info:
    monitor_display_name: "VLAN Depends on Underlying Network Devices"
  register: result

- name: Get all monitors targeting the VLAN class
  microsoft.scom.monitor_override_info:
    monitor_target_class: "VLAN"
  register: result

- name: Iterate over every monitor and its overrides
  ansible.builtin.debug:
    msg: "Monitor {{ item.display_name }} has {{ item.overrides | length }} override(s)"
  loop: "{{ result.monitors }}"

Key

Description

List of monitors that matched the query. Empty when no monitors are found.

string

The display name of the monitor.

boolean

Whether the monitor is enabled by default (before any override).

The unique GUID of the monitor.

Whether the override is enforced (cannot be further overridden at a lower scope).

The GUID of the monitor this override belongs to.

Returned: success

The unique GUID of the override itself.

The monitor property or configuration parameter being overridden.

Returned: success

The scope the override acts on. Class means the override applies to the whole target class with no further restriction. Group means the override is scoped to a SCOM group (instance or group class definition).

string

Returned: success

The display name of the class the monitor targets. Empty when the class cannot be resolved.

The .NET type name of the monitor (e.g. ManagementPackUnitMonitor).
