microsoft.scom.notification_subscriber module – Manage SCOM notification subscribers.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.notification_subscriber.

New in microsoft.scom 2.0.0

Synopsis

  • Creates or Removes a SCOM notification subscriber (a notification recipient).

  • Subscriber devices include E-Mail (SMTP), Text Message (SMS), and Instant Message (IM).

  • After a subscriber is created it cannot be changed.

  • To change subscriber’s devices, remove the subscriber with state=absent and recreate it with state=present.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

devices

list / elements=dictionary

The list of devices (addresses) that belong to the subscriber.

Required when state=present.

Default: []

address

string / required

The device address.

For smtp provide a plain email address (for example user@contoso.com).

For sms provide the phone number without a prefix (for example 2065551212).

For sip provide the SIP username without a prefix (for example SarahJ).

name

string

A friendly name for the device.

Defaults to the full SCOM address string when not provided.

type

string

The device type, which determines the channel type and protocol.

smtp - E-Mail (SMTP).

sms - Text Message (SMS).

sip - Instant Message (IM).

Choices:

  • "smtp" ← (default)

  • "sms"

  • "sip"

name

string / required

The name of the notification subscriber.

Used as the identity for creation and for removal.

state

string

present ensures the subscriber exists, creating it if necessary.

absent removes the subscriber if it exists.

Choices:

  • "present" ← (default)

  • "absent"

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Create an email notification subscriber
  microsoft.scom.notification_subscriber:
    name: "Operations Team"
    devices:
      - address: "ops@contoso.com"
        name: "Ops mailbox"

- name: Create a subscriber with multiple email devices
  microsoft.scom.notification_subscriber:
    name: "On-call Engineers"
    devices:
      - address: "primary@contoso.com"
      - address: "secondary@contoso.com"

- name: Create a subscriber with an SMS device
  microsoft.scom.notification_subscriber:
    name: "Sarah Jones"
    devices:
      - address: "2065551212"
        type: sms
        name: "Sarah mobile"

- name: Create a subscriber with an instant message (SIP) device
  microsoft.scom.notification_subscriber:
    name: "Sarah Jones"
    devices:
      - address: "SarahJ"
        type: sip
        name: "Sarah IM"

- name: Create a subscriber with email, SMS, and SIP devices
  microsoft.scom.notification_subscriber:
    name: "Sarah Jones"
    devices:
      - address: "sarah.jones@contoso.com"
        type: smtp
        name: "Sarah email"
      - address: "2065551212"
        type: sms
        name: "Sarah mobile"
      - address: "SarahJ"
        type: sip
        name: "Sarah IM"

- name: Remove a notification subscriber
  microsoft.scom.notification_subscriber:
    name: "Operations Team"
    state: absent
