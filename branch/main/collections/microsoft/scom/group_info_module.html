microsoft.scom.group_info module – Retrieve information about SCOM groups.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.group_info.

Synopsis

  • Returns the list of SCOM groups.

  • Optionally filters to a single group by internal full name or display name.

  • This is a read-only module and never changes the SCOM environment.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

display_name

string

Restrict the result to the group with this display name.

Takes precedence over name when both are provided.

name

string

Restrict the result to the group with this internal full name.

Ignored when display_name is provided.

When both name and display_name are omitted, all groups are returned.

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Get all groups
  microsoft.scom.group_info:
  register: all_groups

- name: Get a single group by display name
  microsoft.scom.group_info:
    display_name: "Contoso Group"
  register: contoso_group

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

groups

list / elements=dictionary

The list of groups. Empty when none match.

Returned: always

configured_members

list / elements=dictionary

The monitoring object GUIDs stored in the management pack XML for groups created by microsoft.scom.group. Available immediately after group creation or membership update - does not require GroupPopulator to have run. Empty for built-in or third-party groups.

Returned: success

id

string

The monitoring object GUID as stored in the management pack.

Returned: success

display_name

string

The display name of the group.

Returned: success

full_name

string

The full internal name of the group class.

Returned: success

id

string

The internal GUID of the group.

Returned: success

members

list / elements=dictionary

The monitoring objects currently related to the group at runtime, as returned by SCOM’s GroupPopulator discovery. This list may be empty for recently created or updated groups until GroupPopulator completes (typically 30-120 seconds after creation). Use configured_members for immediate consistency checks.

Returned: success

display_name

string

The display name of the member monitoring object.

Returned: success

id

string

The internal GUID of the member monitoring object.

Returned: success

name

string

The full internal class name of the member monitoring object.

Returned: success

name

string

The full internal name of the group class.

Returned: success
