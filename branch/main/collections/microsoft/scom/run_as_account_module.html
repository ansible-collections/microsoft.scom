microsoft.scom.run_as_account module – Manage SCOM Run As Accounts.

Note

This module is part of the microsoft.scom collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install microsoft.scom. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: microsoft.scom.run_as_account.

Synopsis

  • Creates, Removes, and Updates Credentials of SCOM Run As Accounts.

  • Supports 7 SCOM credential types.

  • Existing account credentials can be updated with update_credential=true.

  • Only one account name per account_type can be created.

  • Passwords and community strings are never returned by the module.

Requirements

The below requirements are needed on the host that executes this module.

  • Must execute on the SCOM Management Server via WinRM

  • SCOM Operations Console installed on the target host (provides the OperationsManager PowerShell module or the legacy Microsoft.EnterpriseManagement PSSnapins)

  • SCOM 2012 R2, 2016, 2019, or 2022

  • SCOM Operators role (minimum) for the executing account

Parameters

Parameter

Comments

account_type

string

Credential type of the RunAs account.

Required when state=present or when name is used with state=absent.

Not required when id is used with state=absent.

Immutable once the account is created.

Determines which credential parameters are required.

windows — requires username, password, domain.

action_account — requires username, password, domain.

community_string — requires community_string.

basic_authentication — requires username, password.

simple_authentication — requires username, password.

digest_authentication — requires username, password.

binary_authentication — requires binary_file_path.

Choices:

  • "windows"

  • "community_string"

  • "basic_authentication"

  • "simple_authentication"

  • "digest_authentication"

  • "binary_authentication"

  • "action_account"

binary_file_path

string

Absolute path on the SCOM management server to the binary account file.

Required for account_type=binary_authentication.

Can be updated with update_credential=true.

community_string

string

SNMP community string.

Required for account_type=community_string.

Can be updated with update_credential=true.

Using Ansible Vault or an encrypted string is highly recommended when using real account secrets.

description

string

Free-text description for the RunAs account.

Applied when the account is created and cannot be changed.

domain

string

Windows domain for the credential.

Required for account_type=windows and account_type=action_account.

For a local user account, the server’s hostname can be specified as the domain.

Can be updated with update_credential=true.

id

string

GUID of the RunAs account.

Mutually exclusive with name.

For state=present, used only for updating an existing account. Fails if not found.

For state=absent, removes the account with that GUID.

Obtain this value with the run_as_account_info module.

name

string

Display name of the RunAs account.

Mutually exclusive with id.

Required together with account_type when creating a new account.

For state=present with update_credential=true, the name must be unique; if duplicates exist the module fails and instructs the user to use id instead.

For state=absent, the account is removed when exactly one match is found. If duplicates exist the module fails and instructs the user to use id instead.

password

string

Password for the credential.

Required for account_type=windows, account_type=action_account, account_type=basic_authentication, account_type=simple_authentication, and account_type=digest_authentication.

Can be updated with update_credential=true.

Using Ansible Vault or an encrypted string is highly recommended when using real account secrets.

state

string

present creates the account if it does not exist, or updates its credentials when update_credential=true.

absent removes the account. Supply either name + account_type or id.

Choices:

  • "present" ← (default)

  • "absent"

update_credential

boolean

Whether to update the credential on existing accounts.

When true will always result in a change when executing the module.

All credential parameters required by the account_type must be supplied together.

Choices:

  • false ← (default)

  • true

username

string

User name for the credential.

For account_type=windows and account_type=action_account this is the account name without the domain (the domain is supplied separately via domain).

For account_type=basic_authentication, account_type=simple_authentication, and account_type=digest_authentication this is the full account name.

Can be updated with update_credential=true.

Notes

Note

  • These modules must run directly on the SCOM Management Server via WinRM. The OperationsManager PowerShell module is only installed on hosts where the SCOM Operations Console has been installed, and the SDK auto-connects to the local Management Group on import. Running on any other Windows host will fail.

  • Supported SCOM versions: 2012 R2, 2016, 2019, 2022.

  • The account executing this module must hold at minimum the SCOM Operators role on the Management Group. Administrative operations (e.g. importing management packs) require the SCOM Administrators role.

Examples

- name: Create a Windows RunAs account
  microsoft.scom.run_as_account:
    state: present
    name: "Contoso SQL Monitoring Account"
    account_type: windows
    domain: "CONTOSO"
    username: "svc-sql-mon"
    password: "{{ vault_sql_mon_password }}"
    description: "Credential for SQL Server monitoring"
  register: result

- name: Store the returned GUID for later use
  ansible.builtin.set_fact:
    sql_mon_guid: "{{ result.run_as_account.id }}"

- name: Update the Windows credential
  microsoft.scom.run_as_account:
    state: present
    name: "Contoso SQL Monitoring Account"
    account_type: windows
    domain: "CONTOSO"
    username: "svc-sql-mon"
    password: "{{ vault_new_password }}"
    update_credential: true

- name: Update a specific account by id when multiple accounts share the same name
  microsoft.scom.run_as_account:
    id: "{{ sql_mon_guid }}"
    domain: "CONTOSO"
    username: "svc-sql-mon"
    password: "{{ vault_new_password }}"
    update_credential: true

- name: Create a Community String RunAs account
  microsoft.scom.run_as_account:
    state: present
    name: "Network Device SNMP Community"
    account_type: community_string
    community_string: "{{ vault_snmp_community }}"

- name: Create a Binary Authentication RunAs account
  microsoft.scom.run_as_account:
    state: present
    name: "Binary Auth Account"
    account_type: binary_authentication
    binary_file_path: >-
      C:\SCOM_Export\binary_account.pem

- name: Remove the RunAs account by GUID
  microsoft.scom.run_as_account:
    state: absent
    id: "{{ sql_mon_guid }}"

- name: Remove the RunAs account by name and type (fails if duplicates exist)
  microsoft.scom.run_as_account:
    state: absent
    name: "Contoso SQL Monitoring Account"
    account_type: windows

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

run_as_account

dictionary

Details of the RunAs account after applying changes.

Returned when state=present and the account was found or created.

Not returned when state=absent.

Returned: when state=present and check mode is off.

account_type

string

SCOM internal class name of the credential type.

Maps to the account_type parameter as follows.

SCOMWindowsCredentialSecureData - windows.

SCOMCommunityStringSecureData - community_string.

SCOMBasicCredentialSecureData - basic_authentication.

SCOMSimpleCredentialSecureData - simple_authentication.

SCOMDigestCredentialSecureData - digest_authentication.

SCOMGenericSecureData - binary_authentication.

SCOMActionAccountSecureData - action_account.

Returned: success

description

string

Description of the RunAs account.

Returned: success

domain

string

Domain of the stored credential.

Populated for windows and action_account account types; empty for others.

Returned: success

id

string

Unique GUID of the RunAs account.

Returned: success

last_modified

string

Timestamp of the last modification (yyyy-MM-dd HH:mm:ss z).

Returned: success

name

string

Display name of the RunAs account.

Returned: success

user_name

string

User name of the stored credential.

Populated for windows, action_account, basic_authentication, simple_authentication, and digest_authentication account types.

Returned: success
